# Juno Life

Une simulation de vie impitoyable. Jusqu'à ce que la mort vous sépare.

## Jouer en ligne

👉 **https://votre-pseudo.github.io/juno-life/**

## Installation mobile (PWA)

1. Ouvrez le lien ci-dessus dans Chrome (Android) ou Safari (iOS).
2. Appuyez sur "Ajouter à l'écran d'accueil".
3. Jouez hors-ligne à volonté !

## Développement local

```bash
npm install --legacy-peer-deps
npm run dev
```
